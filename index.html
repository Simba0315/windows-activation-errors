Windows activation error codes: what they mean and what to try first

Windows and Office show activation problems as a hex code, for example 0x80072F8F. The code tells you which part failed: the key, the clock, the network or your permissions. Before you buy anything or reinstall, find your code below and do the first check. Most of these are fixed in a few minutes.

Where to find the code

On Windows 10 and 11 open Settings, then System (or Update & Security), then Activation. The error appears under the activation state. In Office it appears in the activation window or under File, Account.

The common codes

CodeWhat it meansFirst thing to check
0x80072F8FWindows could not make a secure connection to Microsoft, usually because the PC clock is wrong.Set the date, time and time zone automatically, sync the clock, turn off a VPN or proxy, try again.
0x80072EE7Windows could not resolve the name of Microsoft's activation server.Check that the internet works, then the DNS settings and the hosts file, and any filter or firewall that blocks Microsoft addresses.
0x8007267CNo DNS server is set on the network adapter, or there is no connection at all.Set the adapter to get DNS automatically or enter a DNS server, test a lookup, activate again.
0x8007251DA volume (KMS) client found no KMS host record in DNS.At work, ask IT for the KMS host. At home, the PC needs a retail key instead of a volume key.
0x80070005Access denied: an activation command ran without administrator rights.Open Command Prompt or Terminal as administrator and run the command again.
0xC004C060Microsoft marked the key as no longer valid.Check where the key came from. A blocked key cannot be repaired; the fix is a valid key.
0x80004005Unspecified error: something failed without a clearer code.Run the activation troubleshooter, repair system files with DISM and SFC, enter the key again.

Two habits that save time

First, read the code, not just the message: different problems often share the same sentence ("We can't activate Windows on this device"). Second, fix the network and the clock before touching the key. A good key on a PC with a wrong clock fails the same way as a bad key.

If you change hardware, sign in with a Microsoft account before the change: Windows 10 and 11 can then be reactivated with the Activation troubleshooter after a motherboard swap.
